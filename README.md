## Deskripsi Singkat
Proyek ini adalah website "Warung Pangsit Mie Ayam & Bakso Meteor", sebuah solusi digital berbasis data nyata yang kami kembangkan untuk membantu UMKM lokal di Kota Palu memperluas jangkauan informasinya. Sesuai dengan aturan submission, website ini dibangun murni dari awal menggunakan struktur HTML Semantik, CSS, dan Vanilla JavaScript tanpa menggunakan template, framework, maupun library eksternal.  

Website ini terdiri dari tiga halaman utama yang saling terhubung: Beranda, Katalog Menu, dan Lokasi & Kontak. Untuk memenuhi kriteria manipulasi DOM, kami mengimplementasikan fitur filter kategori menu secara dinamis, navigasi mobile (hamburger menu), serta popup/modal panduan pemesanan. Seluruh tata letak juga telah dirancang sepenuhnya responsif agar dapat beradaptasi dengan baik di berbagai ukuran perangkat keras.
